# Submission package

`main.tex` + `refs.bib` → `main.pdf` (7 pp total: body runs to just past p5,
references pp 6–7; anonymized, `plainnat`). Build:
`pdflatex main && bibtex main && pdflatex main && pdflatex main`.
Body length is *not* yet trimmed to a venue limit — see the note below on
formatting. Content was prioritised over hitting a self-imposed page count.

**`REPRODUCE.md`** is the entry point for anyone checking the numbers: exact
commands for both n=50 headline cells, SHA/md5 digests of the two checkpoints
that produced them (verified byte-identical to the machine that ran them), and
a `--mock-env` smoke test needing no LIBERO, no GPU, and no network. It states
plainly that reproduction means landing inside the Wilson interval rather than
on the point estimate, and that a cross-stack mismatch may be this paper's own
audit-stack finding recurring rather than a failed reproduction.
`../../models/README.md` is the release manifest (digests, LIBERO commit,
pinned versions).

Every number in the PDF traces to a `*_results.json` artifact; the full
ledger (run ids, protocols, selection looks, protocol deviations,
falsified predictions) is in `../MANUSCRIPT_v2.md` App. D, and the
complete experimental log — including every negative result and
retraction — is `../paper.md`. Runs made after commit `faf832d` embed their own
`argv` and git commit in `results.json`; the two headline artifacts predate
that field, which is why it exists.

Not yet in this package, and deliberately so:
* Figures F1–F4 exist (`../visuals/`, regenerated by
  `../render_results_figs.py`) but are not yet placed in the LaTeX; the
  4-page draft states every figure's content in text and tables.
* Venue formatting (CoRL/ICRA style files, page limits, checklists) is
  not applied — the class is plain `article` pending a venue choice.
* No submission has been made. That step needs the author's decision and
  credentials; nothing here should be read as a submitted or reviewed
  artifact.
